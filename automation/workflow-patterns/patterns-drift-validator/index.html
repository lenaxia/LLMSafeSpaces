    The patterns-drift validator — a workflow that files stories when examples rot¶

    Description: The async tier of example validity — a weekly workflow whose leading script node hashes the drift surface (both example catalogs plus the tool-catalog sources), routes on change, and whose agent leg walks every example against live reality, filing ONE Sprint Board story when the examples have rotted and nothing when they are clean.

    This is the async sibling of the repo's static drift pins: CI catches mechanical rot (tool names, payload schemas, placeholder grammar) at merge time; this workflow catches semantic drift WEEKLY against the live surface — renamed tools, changed validation rules, stale advice — and reports it the board-native way: a story with per-example pointers, never a direct edit to the docs. It also validates ITSELF: this file is one of the examples the walk covers (the dogfood ruling — the spec below is the live workflow, byte-for-byte).

    The workflow¶

    ```yaml kind=workflow-spec nodes: - id: gather type: script data: language: python handler: | import glob, hashlib, os

        REPO = "/workspace/LLMSafeSpaces"
    STATE = "/workspace/patterns-drift/state.txt"
    DIRS = [("sprint-board-patterns", "board"), ("workflow-patterns", "workflow")]
    # Precedence: a pinned pre-merge copy wins, then the pod-served
    # set, then the repo checkout's sources of truth.
    ROOTS = [
        ("/workspace/patterns-drift/example-sources", "pinned"),
        ("/sandbox-runtime/docs", "pod"),
        (os.path.join(REPO, "docs/automation"), "repo"),
    ]
    PROJECT_ID = "f83bcda7-305b-4cb8-ae13-b338e4c37515"
    EPIC_ID = "24bfec2b-60bf-4959-8b20-3c44adbd361c"

    def sha256_file(path):
        h = hashlib.sha256()
        with open(path, "rb") as fh:
            for chunk in iter(lambda: fh.read(65536), b""):
                h.update(chunk)
        return h.hexdigest()

    def handler(input):
        root, label = "", "none"
        for candidate, lab in ROOTS:
            if os.path.isdir(os.path.join(candidate, DIRS[0][0])):
                root, label = candidate, lab
                break
        files = []
        if root:
            for dirname, _kind in DIRS:
                for path in sorted(glob.glob(os.path.join(root, dirname, "*.md"))):
                    files.append({"dir": dirname, "file": os.path.basename(path),
                                  "sha256": sha256_file(path)})
        examples_h = hashlib.sha256("".join(
            f["dir"] + "/" + f["file"] + "@" + f["sha256"] + "\n" for f in files).encode()).hexdigest()
        # The tool-catalog sources: the same files the #1415/0059
        # drift pins read (agentd mcp_server.go + the pkg/mcp
        # projection) — a renamed or reworded tool moves this hash.
        catalog_paths = [os.path.join(REPO, "cmd/workspace-agentd/mcp_server.go")]
        catalog_paths += sorted(glob.glob(os.path.join(REPO, "pkg/mcp", "*.go")))
        catalog_h = hashlib.sha256("".join(
            p + "@" + (sha256_file(p) if os.path.isfile(p) else "missing") + "\n"
            for p in catalog_paths).encode()).hexdigest()
        digest = examples_h[:16] + "-" + catalog_h[:16]
        prev = ""
        if os.path.isfile(STATE):
            with open(STATE) as fh:
                prev = fh.read().strip()
        base = {"digest": digest, "example_root": label, "files": files,
                "file_count": len(files), "epic_id": EPIC_ID, "project_id": PROJECT_ID}
        if not files:
            # Nothing to validate yet (pod dirs absent, repo branch
            # pre-merge): quiet leg, and do NOT advance the state —
            # the walk runs the day sources appear.
            base.update({"changed": False, "reason": "no example sources materialized yet"})
            return base
        # Mark-after-effect: gather does NOT write the state here;
        # the agent writes it as its FINAL step, so a failed walk
        # leaves the surface stale and the next fire retries
        # (retry-until-validated, per idempotency-and-gates.md).
        base.update({"changed": digest != prev, "reason": ""})
        return base

      The wiring — weekly cron¶

      sh kind=shell trigger_create {trigger: {name: "patterns-drift-validator-weekly", sourceType: "cron", sourceConfig: {expr: "23 4 * * 1", tz: "UTC"}, workflowId: "<the workflow id — camelCase field name>"}}

    No inputSchema (envelope fires are not schema-enforced) and NO inline gate script — see trap 1. The trigger stays armed forever: when the surface is unchanged the run costs two script nodes and stops (trigger_fires shows the run; workflow_runs shows the quiet line).

    The run book¶

    • State: /workspace/patterns-drift/state.txt holds the last VALIDATED digest (written by the agent leg, never by gather). Force a re-walk by deleting it; the next fire behaves like first sight.
    • Pinned sources: drop a pre-merge copy of both catalogs under /workspace/patterns-drift/example-sources/ to validate a revision under review — it wins over the pod-served and repo sets until removed.
    • Findings: drift becomes ONE story in the reference epic, worked like any other story (AI reviewer until APPROVED; the validator never edits the docs itself).
    • Diagnosis: workflow_runs for the walk, trigger_fires for the schedule; disarm with trigger_update {enabled: false} (the weekly fire is cheap, so the default is to stay armed).

    A clean run's whole footprint:

    text kind=output patterns clean: no findings filed

    The traps this example teaches¶

    • The gate lives in the DAG, not the trigger. An inline gate script is REJECTED alongside workflowId (a DAG carries its own script nodes) — so the hash-and-dedup that a routine's gate script would do becomes the leading script node plus a condition. Same discipline (state dedup across fires), native placement.
    • Mark AFTER the effect, not before. Gather compares but never writes the state; the agent writes it as its final step. A walk that dies mid-flight leaves the surface stale and the next fire retries — the retry-until-validated posture (idempotency-and-gates.md), chosen because the effect (a filed story) must not be lost to a crash.
    • State under /workspace, never /sandbox-runtime. The workspace volume is durable; the runtime dir is tmpfs and dies with the pod (idempotency-and-gates.md).
    • Conditions pass their input through. validate sits downstream of route yet resolves {{.digest}}, {{.files}} and friends against GATHER's output — the condition's downstream sees the condition's input (placeholder-rules.md).
    • Findings are board-native, docs are read-only. Drift is reported as a story with per-example pointers, worked through the normal review flow — a validator with edit rights is a self-merging reviewer.
