## Objective

Land the workflow CRUD handlers that wrap the store (US-64.3) + DAG validator (US-64.4 part 1). These are the HTTP-facing endpoints that users call to create, list, get, update, and delete workflow definitions.

## Work Completed

### `api/internal/handlers/workflows.go`
- `WorkflowsHandler` struct with narrow interfaces (workflowStore, workflowQuotaChecker, workflowAuditLogger)
- Two constructors: `NewUserWorkflowsHandler`, `NewOrgWorkflowsHandler`
- User endpoints: `UserList/Create/Get/Update/Delete`
- Org endpoints: `OrgList/Create/Get/Update/Delete`
- Shared CRUD logic: `list/create/get/update/del` methods scoped by `(ownerType, ownerID)`
- **DAG validation on create**: parses spec YAML → `ValidateSpec` → rejects with 400 + details on validation failure
- **DAG validation on update**: re-validates if spec_yaml changed; fetches existing for defaults fallback
- **Slug generation**: `slugify(name)` if slug not provided; validated against slug regex
- **Quota enforcement**: `checkQuota` reads `workflows.maxPerUser`/`maxPerOrg` from instance settings; rejects at limit with 409
- **Audit logging**: `logCreate` emits `workflow.create` events (deferred via `SetAudit`)
- **Error mapping**: `ErrNotFound` → 404, unique violation → 409, store errors → 500
- Follows `mcp_servers.go` conventions exactly (scope-specific → shared delegation pattern)

## Key Decisions

1. **No crypto in the handler** — workflows don't carry secrets (unlike MCP servers). The handler is pure CRUD + validation. The webhook-secret crypto envelope is wired in US-64.5 (trigger CRUD).
2. **Spec YAML is expected to be JSON** — v1's YAML editor sends JSON through the API. If the content isn't valid JSON, `ParseSpec` fails with a clear error. YAML→JSON conversion is a frontend concern.
3. **Re-validation on spec_yaml change** — update fetches the existing workflow for the defaults fallback. If spec_yaml didn't change, no re-validation needed (the stored spec is already validated).
4. **Quota = 0 means unlimited** — matches the settings convention. Non-zero values are hard caps.
5. **Slug auto-generated from name** — if the caller doesn't provide a slug, `slugify(name)` produces one. Both are validated independently.
