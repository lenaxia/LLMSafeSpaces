  - **Single-in-flight-per-workflow (D8):** partial UNIQUE index `uq_workflow_run_single_inflight ON workflow_runs(workflow_id) WHERE status IN ('queued','running')` — atomically rejects a second concurrent run without a check-then-insert race

## Key Decisions

1. **No `manual` in `source_type` CHECK** — manual runs go through `POST /workflows/:id/runs` with `trigger_id = null` (design D5). The CHECK constraint enforces `cron` + `webhook` only.
2. **Error code enum bounded at DB layer** — the CHECK constraint prevents typos / unknown codes from being persisted. `ValidRunErrorCode()` in Go mirrors the set exactly (13 codes).
3. **Leading digits allowed in workflow/trigger names** — the regex `^[a-zA-Z0-9][a-zA-Z0-9 _-]{0,127}$` permits names like "2fa-check" (matches `mcp_servers` convention).
4. **`trigger_fires.trigger_id` is NOT NULL with CASCADE** — fire audit rows are owned by their trigger. `workflow_runs.trigger_id` IS nullable (manual runs have `trigger_id = null`).
5. **`workflows.target_workspace_id` uses `ON DELETE SET NULL`** — deleting a workspace doesn't cascade-delete the workflow definition; the workflow loses its pinned target but remains runnable with caller-supplied workspace.
6. **`workflow_runs.workspace_id` uses `ON DELETE CASCADE`** — runs belong to the workspace; deleting it removes the runs. (Run history is per-workspace.)
