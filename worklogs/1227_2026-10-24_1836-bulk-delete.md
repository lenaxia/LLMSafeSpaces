## Design deltas vs #1937 (documented, all pinned)

1. **Idempotent retry for a DESTRUCTIVE variant — absence ≡ miss ≡
   foreign**: the claim/move pre-checks read observable row state
   (in_progress / at-target → done). A delete's "already-done" state
   is row ABSENCE, indistinguishable from a miss and from a foreign
   row. All three render the SAME bare `not_found` item (byte-equal
   code AND detail — the item is constructed identically for all
   three). Rendering absence as `done` would (a) fabricate an outcome
   for a foreign probe and (b) DISCLOSE foreign-row existence (an
   existing-but-foreign row returning not_found while an absent row
   returned done). Contract 2's substance — retry safety — holds: no
   batch error, no second write/audit/abort on re-submit (pinned:
   `TestBulk_DeleteIdempotentResubmit`,
   `TestBulk_DeleteTripleEqualityNeverDisclose`).
2. **One shared `reconnect` flag** across the batch (the
   BulkMoveStage shared-toStage pattern; per-item flags would be N
   single calls).
3. **Echo fields on done items**: `orphaned_dependents` +
   `reconnected` ride `BulkItemResult` (omitempty) — the single form's
   `DeleteResult` facts, surfaced so the sweep caller sees affected
   parties without an events round-trip (the issue's round-trip-economy
   mandate). Precedent: `Escalated` is the claim variant's
   variant-specific field. No token-class field ever renders (#1864
   ruling; pinned by the JSON-shape test).

## CI round 1 (Secrets Integration failure → fixed in-place)

Two subtests failed on the FIRST CI pass — both MY assertion bugs,
not implementation bugs: the byte-equality pins compared whole
`BulkItemResult` structs, but `Ref` echoes each caller's ref VERBATIM
(by design), so items for two different submitted refs can never be
structurally equal. The never-disclose property lives in the ERROR
payload (byte-identical code + detail across absence/miss/foreign —
the code assertions all passed; only the struct-equality overreach
failed). Fixed to compare `Error` payloads; same fix applied to the
e2e's miss ≡ foreign pin. (This is also WHY local PG absence mattered
less: the failure class was assertion logic, not PG behavior — but
the honest boundary stands: local execution would have caught it.)
