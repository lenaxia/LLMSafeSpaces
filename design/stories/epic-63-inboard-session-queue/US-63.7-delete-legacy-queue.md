# US-63.7: Delete Legacy Queue — `msgqueue`, `drainQueuedMessage`, Message-ID Hack, 409-Requeue, Stranded-Queue Sweep

**Epic:** 63 - Inboard Session Queue
**Priority:** Normal
**Depends on:** US-63.3 (enqueue migrated), US-63.4 (abort migrated), US-63.6 (frontend migrated), **US-63.9 (stranded-input recovery — the stranded-queue sweep cannot be deleted until a replacement drain trigger exists)**, US-63.10 (fresh-load visibility decision)

## User Story

As the codebase, I want the external Redis queue and its incident-scarred workarounds deleted — so that the entire bug class (message-id hack, 409-requeue, destructive abort, stranded-queue sweep) is eliminated.

## Background

Once US-63.3, US-63.4, US-63.6, and **US-63.9** are stable in production for one release cycle with the feature flag on, the legacy path is dead code. This story deletes it wholesale. This is the payoff of the epic — roughly 300+ lines of complexity removed.

> **Stress-test correction:** the original draft listed only US-63.3/63.4/63.6 as dependencies. That was unsafe — deleting the stranded-queue sweep before US-63.9 ships a replacement drain trigger would reintroduce the exact "queued message strands after pod crash" bug the sweep was built to fix (Epic 63 F15-F16). US-63.9 is now a hard dependency.

## Acceptance Criteria

- [ ] `api/internal/services/msgqueue/` is deleted in its entirety (`service.go`, `service_test.go`).
- [ ] `generateOpencodeMessageID` and its 60-line doc comment (`service.go:27-86`) recording the 2026-06-29 role-flip/silent-drop incident are gone.
- [ ] `ProxyHandler.queueSvc` field is removed; all 8 call sites (`EnqueueMessage`, `ListQueue`, `DeleteQueueMessage`, `redirectPromptToQueue`, `drainQueuedMessage`, `AbortSession` peek+clear, `reconcileSessionState`, `app.go:1244` dispose) are removed or rewritten.
- [ ] `drainQueuedMessage` (`proxy_events.go:442-498`), `sendQueuedToOpencode`, `errSessionBusy`, `maxQueueRetries`, and the 409-requeue branch (`:460-474`) are deleted.
- [ ] `redirectPromptToQueue` (`proxy_handlers.go:114`) is deleted.
- [ ] `flushAndAbortAfterIdle` (`proxy_handlers.go:674-750`) is deleted.
- [ ] The stranded-queue sweep branch of `reconcileSessionState` (`proxy_events.go:652-663`) is deleted **only after US-63.9 lands a replacement drain trigger**; the stale-`activeSess` reconciliation (OOM/SIGTERM case, `:632-650`) is **retained** — it is orthogonal to the queue.
- [ ] The `LLMSAFESPACE_V2_SESSION_QUEUE` feature flag is removed; V2 is the only path.
- [ ] The `DELETE /sessions/:sid/queue/:messageId` endpoint (dismiss) is removed or returns 410 Gone (coordinate with US-63.8 SDK impact).
- [ ] The `GET /sessions/:sid/queue` (list) endpoint is removed/retained per the US-63.10 decision.
- [ ] `app.go` queue-service wiring (`:203-204`, `:1244`) is removed; the Redis client borrowing for the queue is gone (Redis may still be used by `wsstate` from Epic 45 — that is unaffected).
- [ ] All tests in `proxy_queue_test.go`, `proxy_queue_drain_miss_test.go` are deleted or rewritten to cover the V2 paths.
- [ ] `ForceAbortSession` (Epic 44, `admin_session.go`) is retained and unchanged.
- [ ] `CHANGELOG.md` records: (a) queue is now inboard/durable; (b) abort is non-destructive (queued messages survive); (c) dismiss/revoke is removed.
